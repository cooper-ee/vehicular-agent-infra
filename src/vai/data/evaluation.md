# 推理服务评估约定

TTFT 是从客户端发起请求到收到第一个非空文本增量的时间。工具调用的首个 JSON、SSE accepted 事件或空 content 不作为首个文本 token。网络分块可能包含多个 token，因此不根据 SSE 事件数量推断 token 数。

P95 对成功请求端到端时延计算，同时独立报告错误率。超时请求保留在原始 CSV，不能直接删除后只宣称系统延迟低。吞吐量应说明请求数/秒还是输出 token 数/秒，后一项依赖后端 usage 计数。

并发、输入长度、输出上限、模型、量化、KV cache、硬件与后端版本需一起保存。离线 mock 只验证编排与协议，不证明 vLLM 连续批处理或 GPU 性能收益。
