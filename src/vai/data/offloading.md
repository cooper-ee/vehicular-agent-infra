# 车路协同卸载实验说明

本文件是本仓库自建的演示知识库，不是交通法规或实测报告。

任务卸载应同时考察上传时延、排队等待、服务时间与结果回传。输入数据以 MB 计、带宽以 Mbps 计时，上传时间毫秒数为 1000 × 8 × input_mb / bandwidth_mbps。MB 在这里采用十进制定义。

只选最快 GPU 可能导致队列拥塞。预计完成时间应考虑当前排队工作量、任务类型兼容性、节点内存以及模型是否驻留。负载均衡不能仅比较不同硬件的任务数量，需同时看归一化工作量和时限违约率。

不可行任务应拒绝或转发到可服务节点，不能把无法部署视觉语言模型的 Nano 当作通用大模型节点。这个实验助手只提供资料检索和估算，不会控制车辆或自动执行真实任务卸载。
